# Pro One Banking

Pro One Banking is a pretend Kidtopia Money wallet website for Robox. It uses the same browser `localStorage` wallet key as Robox on the public GitHub Pages site:

`pro-one-banking-wallets-v1`

When Robox connects a player, the Pro One Banking website can show the matching Kidtopia Money balance and transaction history. This is not real banking and does not use real money.

Version 2 removes the old 100,000 transfer cap. Deposits add the exact Kidtopia Money amount typed into the banking website.
